# CardGlow

Trang trí viền thẻ theo vị trí con trỏ trên các màn hình trải nghiệm.

## Nội dung

- `card-glow.ts`, `card-glow.spec.ts` — Directive và spec nội suy độ sáng.
- `card-glow.css` — CSS hiệu ứng do styles.css nạp toàn cục.

App dùng directive `appCardGlow` từ `@app/shared`.

Hiệu ứng dùng FrameBudget trong shared.
