# Button

Nút standalone có API làm việc với nút HTML bên trong.

## Nội dung

- `button.ts` — Khai báo app-button và input variant, disabled, type.
- `button.html`, `button.css` — Markup nút, nội dung chiếu qua ng-content và style theo biến màu dự án.

Ví dụ `import { Button } from '@app/shared'`.
