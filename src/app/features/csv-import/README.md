# CsvImport

Đọc CSV, xem trước, ánh xạ cột và xử lý dữ liệu thiếu trước khi áp dụng.

## Nội dung

- `csv-import.ts`, `csv-import.html`, `csv-import.css`, `csv-import.spec.ts` — Component chính, template, CSS và spec.
- `index.ts` — Xuất component chính.

Ví dụ `import { CsvImport } from '@app/features/csv-import'`.

Phụ thuộc vào Các hàm CSV và LabStore.
