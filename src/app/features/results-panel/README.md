# ResultsPanel

Hiển thị chỉ số, biểu đồ sai số và kết quả mô hình.

## Nội dung

- `results-panel.ts`, `results-panel.html`, `results-panel.css`, `results-panel.spec.ts` — Component chính, template, CSS và spec.
- `index.ts` — Xuất component chính.

Ví dụ `import { ResultsPanel } from '@app/features/results-panel'`.

Phụ thuộc vào LabStore và tên hạng tử đa thức.
