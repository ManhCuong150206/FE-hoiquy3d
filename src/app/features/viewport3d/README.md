# Viewport3d

Vẽ các điểm dữ liệu, bề mặt hồi quy và phần minh họa sai số trong Three.js.

## Nội dung

- `viewport3d.ts`, `viewport3d.html`, `viewport3d.css`, `viewport3d.spec.ts` — Component chính, template, CSS và spec.
- `index.ts` — Xuất component chính.

Ví dụ `import { Viewport3d } from '@app/features/viewport3d'`.

Phụ thuộc vào LabStore, phép chiếu mô hình, màu canvas và FrameBudget.
