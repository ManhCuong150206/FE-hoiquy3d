# DataPanel

Thiết lập dữ liệu mô phỏng, tạo lại dữ liệu và mở luồng nhập CSV.

## Nội dung

- `data-panel.ts`, `data-panel.html`, `data-panel.css`, `data-panel.spec.ts` — Component chính, template, CSS và spec.
- `index.ts` — Xuất component chính.

Ví dụ `import { DataPanel } from '@app/features/data-panel'`.

Phụ thuộc vào LabStore và feature nhập CSV.
