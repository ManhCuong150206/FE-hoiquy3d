# AlgorithmNotes

Hiển thị công thức và giải thích cho thuật toán đang chọn.

## Nội dung

- `algorithm-notes.ts`, `algorithm-notes.html`, `algorithm-notes.css`, `algorithm-notes.spec.ts` — Component chính, template, CSS và spec.
- `index.ts` — Xuất component chính.

Ví dụ `import { AlgorithmNotes } from '@app/features/algorithm-notes'`.

Phụ thuộc vào LabStore và các hàm mô tả hạng tử đa thức.
